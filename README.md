# Prototype 5

Salutations. This  is a prototype for a first-person rpg dungeon crawler. Enemies currently do not have pathfinding, and we do not have a dialogue panel to display RPG actions. 

The Skill/Item Commands are for display only and don't have any UI Function as of right now.

Controls

WASD - For Movement
Q-E to turn camera. 

Space to Confirm on Menu
Arrow Keys for Menu Navigation

What went well?

Learning how to setup an RPG menu system and reusing the grid structure to fit a first-person dungeon crawler. 


What didn’t go well?

Fitting the time to add a minimap function that hovers over player and also shows walls. 

What challenges did you face?

Trying not to get lost in making to many concepts and sticking to one thing at a time.


What would I aim to do differently?


I would want to make sure to focus on just the RPG aspect until it feels fully fleshed out, then work on enemy Pathfinding,.


If I had more time, I would do Pathfinding, adding a Menu System, and having a displayed minimap that perfectly grabs player position and shows all the walls.


and if I had a little extra time, I would have like a RoomManager or Transition Mwanager, and at least have 2-3 zones for the players to navigate.
